# YIPPEE CLUB FE

TypeScript + React + Next.js App Router 기본 프로젝트입니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```sh
npm ci
npm run dev
```

개발 주소: http://127.0.0.1:3000

```sh
npm run typecheck
npm run build
```

## 브랜치

- `main`: 프레임워크 기본 설정과 시작 페이지만 유지합니다.
- `feature/ui-layout`: 기존 고객용 UI, 에셋, 페이지 이동 흐름을 구성합니다.

백엔드 API 연동과 배포 설정은 별도 작업으로 진행합니다.
