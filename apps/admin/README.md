# YIPPEE CLUB 운영 콘솔

고객용 앱과 같은 레포에 있지만 별도로 실행·빌드·배포하는 Next.js 앱입니다.
고객 앱의 `/admin` 경로는 추가하지 않습니다.

## 로컬 실행

레포 루트에서:

```sh
npm --prefix apps/admin ci
```

`.env.example`을 `.env.local`로 복사하고 `API_PROXY_TARGET`을 실제 BE 주소로 설정합니다.
그다음 루트에서 `npm run admin:dev`를 실행합니다.
주소는 http://127.0.0.1:3100 입니다. 고객용 앱은 기존 3000 포트에서 실행합니다.

## 로그인

고객용 앱에서 가입된 계정 중 BE의 `ADMIN_EMAILS`에 등록된 계정으로 로그인합니다.
화면이나 이메일 문자열만으로 권한을 부여하지 않습니다.
로그인 후 관리자 API 호출이 성공한 계정만 콘솔에 진입합니다.
일반 계정은 403으로 거절되며 관리자 앱의 세션을 지웁니다.
관리자 토큰은 `yippee.admin.session` 키로 탭 세션에 저장합니다.
고객용 토큰을 읽거나 복사하지 않습니다. 401은 갱신, 관리자 403은 접근 해제 처리합니다.
현재 BE 규격은 일반 / 관리자만 구분하며 역할별 세부 권한, MFA API는 없습니다.

## 명세에 연결된 기능

- 대시보드: 결제 확인 필요 주문, 환불 대기, 공개 학습지 수, 최근 주문
- 학습지: 공개 목록 검색, 신규 등록, ID별 부분 수정, 표지·PDF 업로드
- 카테고리: 목록과 등록
- 다운로드: 주문별 학습지 이용권·다운로드 횟수·시각 조회
- 주문: 상태별 조회, 상세·고지 동의·다운로드 이력, 결제사 상태 재확인, 전액 환불
- 환불 요청: 상태별 조회, 다운로드 기록 검토, 승인·반려
- 회원: 이메일 조회, 계정 정지·복구

새로 등록한 학습지는 비공개가 기본입니다. 공개 목록에는 비공개 상품이 포함되지 않습니다.
비공개 상품 전체 조회 API는 없으므로 ID로 일부 필드와 파일을 수정할 수 있습니다.
돈이나 계정 상태를 바꾸는 동작에는 화면 내 최종 확인을 거칩니다.
503은 실패나 완료로 단정하지 않고 서버 상태를 다시 확인하도록 안내합니다.

## 미연동 화면

발급 코드/해시, PDF 스탬프, 정답지·미리보기 별도 파일, 구독,
사진 인증·AI 판독·검수, 문의·리뷰·공지·쿠폰·포인트,
기간별 매출·도전 달성률·AI 판정 비율, 정산·역할별 권한·감사 로그는
현재 명세에 API가 없습니다. 화면에 미연동임을 표시하며 가짜 내역·지표·승인 결과를 만들지 않습니다.

## 검사

```sh
npm run admin:typecheck
npm run admin:build
node --test tests/admin-contract.test.cjs
```

마지막 명령은 레포 루트에서 실행합니다.

## 별도 배포

로컬 관리자 로그인에는 BE의 `CORS_ALLOWED_ORIGINS`에
`http://127.0.0.1:3100`, `http://localhost:3100`을 기존 목록에 추가하고 BE를 재시작해야 합니다.
Next 개발 프록시를 사용해도 브라우저의 Origin은 BE에서 검사됩니다.
이는 로그인 허용 출처 설정이며 관리자 권한은 별도로 서버에서 검사합니다.

배포 플랫폼의 앱 루트를 `apps/admin`으로 지정하고 별도 도메인을 연결합니다.
관리자 앱에 `API_PROXY_TARGET`을 별도로 설정합니다.
운영 배포에는 HTTPS와 관리자 접속 제한을 적용하고, BE 관리자 API 권한 검사를 유지합니다.
앱 분리나 robots 설정 자체는 권한 검사를 대체하지 않습니다.
서버에 비밀키를 추가하지 않았으며 AWS 보안 그룹이나 배포 환경을 변경하지 않았습니다.

## UI 전용 HTML 미리보기

`public/ui-preview.html`을 브라우저에서 직접 열거나,
개발 서버 실행 중 http://127.0.0.1:3100/ui-preview.html 로 접속합니다.
아이디·비밀번호에 아무 문자열이나 입력하면 예시 화면으로 진입합니다.
비밀번호는 저장·전송하지 않으며, 네트워크 API 요청은 CSP로 차단됩니다.
모든 수치와 기록은 예시이며 동작은 현재 페이지 메모리에만 반영됩니다.
실제 관리자 앱의 로그인과 권한 검사에는 영향을 주지 않습니다.
재생성: 레포 루트에서 `node scripts/generate-admin-preview.cjs`
