# PDF 다운로드 중복 집계 수정 (2026-11-27)

- 원인: ViewerPage 진입 시 코드 PDF를 GET하여 미리보기를 만들고, 내려받기 클릭 시 다시 링크 발급 및 GET을 수행했음.
- BE CatalogController는 코드 PDF의 GET마다 pdf_downloads 기록을 삽입하므로 화면 열람+파일 저장에 2회 기록됨.
- 수정: 서버에서 한 번 받아 준비한 코드 PDF Blob을 미리보기·저장·인쇄에서 재사용. 파일명도 발급 응답의 file_name 유지.
- 중단된 화면 요청이 뒤늦게 PDF 발급을 시작하지 않도록 AbortSignal 확인 추가.
- 현재 의미: 화면에서 코드 PDF를 불러오면 1회 증가하고, 같은 화면에서 저장/인쇄는 추가 증가하지 않음. 화면 재진입·새로고침은 새 GET이므로 별도 1회.
- 기존 4회 등 기록은 수정하지 않음. 조회 기록만으로 실제 저장 횟수를 정확히 복원할 수 없음.
- BE 협의: 관리자 지표가 '파일 전송/열람'인지 '사용자의 저장 버튼 클릭'인지 확정 필요. 현재는 전자임. 저장 클릭만 집계하려면 별도의 이벤트 및 중복 방지 계약이 필요함.
