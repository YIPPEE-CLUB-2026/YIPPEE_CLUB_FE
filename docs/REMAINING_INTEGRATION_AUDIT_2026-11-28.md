- 현재 FE 작업 트리, 최신 `BE_API_SPEC.md`, 실제 개발 서버 `https://api.yippeclub.com/v3/api-docs`의 메서드·경로를 대조했습니다.

- **검증 대기**: 코드와 계약 테스트는 있으나 실제 계정·결제·파일 확인이 남음.
- 로컬 develop 최신 커밋: `dda6f94` (PC 레이아웃·최신 API 연결·조회 개선 포함). 마지막 확인된 origin/develop: `3eb0b3c`. 미푸시이므로 운영 배포 완료로 보지 않습니다.

## 5. 이미 추가 연결했으므로 ‘API 없음’ 목록에서 제외할 것

- 부모 관계·연령대·profile_completed.
- 주문 created_at/paid_at/refunded_at/payment_method 및 since.
- 관리자 비공개 포함 학습지 목록·상세·인증 파일.
- 난이도 normal.
- 공개 샘플 이미지, 소장/7일권 주문 옵션, 회원 탈퇴.
- 관리자 일·월·연 매출과 발급 코드·다운로드 이력 조회.

단, 운영 사이트에 반영됐다는 뜻은 아닙니다. 미푸시 코드와 로그인 후 검증 대기를 따로 확인해야 합니다.

## 6. 권장 작업 순서

1. **완료한 FE 보완의 계정별 확인**: 찜 로딩·전체 페이지, 선택 이름 저장, 실제 데이터가 많은 검색 페이지. 로컬 수정은 완료했으며 별도 신규 개발 요청 대상이 아님.
2. **운영 전 확인**: 실제 결제/환불·PDF 권한/횟수·비공개 파일, 운영 키와 관리자 입구 보호.
3. **콘텐츠 입력 계약**: 카테고리 편집/삭제, 장소·준비물·발달 영역·활동 가이드. 관리자와 고객을 한 기능 단위로 연결.
4. **활동 핵심 흐름**: 고객 사진 인증/리뷰 → 관리자 검수 → 활동 기록/배지 → 성장 집계.
5. **운영 콘텐츠**: 문의·공지·프로모션·가이드 CMS·알림.
6. **부가 기능**: 쿠폰·포인트·캐시·저장 카드, 데이터 원장/환불 규칙 먼저 합의.
