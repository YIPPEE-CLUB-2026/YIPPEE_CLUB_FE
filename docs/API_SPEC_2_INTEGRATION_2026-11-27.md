# API_SPEC (2) 연동 인계 — 2026-11-27

기준 명세: `BE_API_SPEC.md` (전달받은 API_SPEC (2).md 원문으로 갱신).

## 이번에 연결한 기능

- 부모 정보: PATCH /users/me에 `relation`, `age_group` 추가. 가입·편집에서 관계 필수, 연령대 선택. 선택 해제는 null. 서버 `profile_completed=false`면 부모 입력 화면으로 안내. 일반/SNS 로그인·세션 복구에 공통 적용.
- 닉네임: 2~10자 완성형 한글·영문·숫자, 낱말 사이 공백 한 칸. 저장 전 trim. 연속 공백·특수문자 차단.
- 주문: `created_at`, `paid_at`, `refunded_at`, `payment_method` 연결. 결제일과 주문일을 구분하고 KST로 표시. 미승인은 결제 전, 무료는 무료 주문, toss는 토스페이먼츠. 카드/간편결제 세부 수단을 추측하지 않음.
- 결제 내역: 최근 1/3/6개월·1년·전체 선택. `/orders?since=YYYY-MM-DD` 사용, 기준은 KST 주문일. 월말을 대상 월 마지막 날로 보정. 로딩·오류·빈 결과 구분.
- 관리자: GET /admin/activities 전체 목록, 공개/비공개·카테고리·제목/설명 필터와 페이지. 수정 시 GET /admin/activities/{id}로 기존 값 로드. 표지·원본 PDF·샘플은 관리자 Authorization 헤더를 붙여 Blob으로 표시하며 object URL은 해제.
- 난이도: 이미 있던 easy/normal/hard UI와 새 BE 계약 일치 확인. 실제 서버 normal 목록 필터 200 확인 (결과 0건).
- PDF: 코드 위치는 BE가 왼쪽 아래에 인쇄. FE는 계속 코드가 포함된 다운로드 결과를 사용하며 좌표를 중복 처리하지 않음.

## 검증 및 남은 확인

- 고객·관리자 타입 검사, 계약 테스트 27개, 고객·관리자 Cloudflare Pages 빌드 통과.
- 로컬 브라우저에서 기존 미완료 계정의 부모 정보 화면 이동과 관계·연령대 입력란을 확인. 관리자 화면은 로그인 필요 상태여서 로그인 후 실제 비공개 목록·파일 확인은 별도 필요.
- 계약 테스트: 부모 필드/null·닉네임 규칙, 주문 날짜와 since, KST 경계/월말, 관리자 샘플 상세 경로, 인증 바이너리·403 처리.
- Swagger에서 새 관리자 목록·상세·파일 경로 확인, 공개 normal 필터 실제 200 확인.
- 실제 부모 정보 저장, 비공개 상품 등록·변경, 결제/환불은 운영 데이터를 변경하므로 이 작업에서 임의 실행하지 않음. 테스트 계정으로 화면 통합 확인 필요.
- 실제 발급 PDF의 왼쪽 아래 코드 위치는 다운로드 파일을 열어 별도 확인 필요.
- 실시간 검색어, 배지 지급/진행률, 사진 인증, 리뷰, 프로필 사진, 카드 저장, 지갑/쿠폰 등은 이번 명세에도 없음. 남은 기능명세 참고.
